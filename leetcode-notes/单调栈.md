# 单调栈

> 及时去掉无用数据，保证栈中数据有序

## 基本思路

类似于看一座座山，高矮各不同，那么面前的山总会挡住后面的较矮的山，那么后面被挡住了就是无用的数据，我们只需记录能看到的

- 例题：[leetcode每日温度]([739. 每日温度 - 力扣（LeetCode）](https://leetcode.cn/problems/daily-temperatures/description/))

解法（从后看）
```java
    public int[] dailyTemperatures(int[] temperatures) {

        int[] res = new int[temperatures.length];

        Deque<Integer> stack = new ArrayDeque<>();

        for(int i=temperatures.length-1; i>=0; i--) {
			while(!stack.isEmpty()&&temperatures[i]>=temperatures[stack.peek()])   
			stack.pop();

            if(stack.isEmpty()){

                res[i]=0;

            }else{

                res[i]=stack.peek()-i;

            }

            stack.push(i);

        }

        return res;

    }
```
## 特点

> 可以在**O（n）时间复杂度**获取数组中每个元素前/后第一个小于/大于它的值的数组元素的下标

需要分析题目，如果需要存在单调栈的特点，则应用
