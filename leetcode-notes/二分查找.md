# 二分笔记
## 基本写法

> 注意l,r外的**循环不变量**

- 以下面函数**lowerBound**为例，该函数将返回数组中大于等于target的第一个index
```java
    private int lowerBound(int[] nums,int target){

        //return the index >= target if exists or with the result as nums.length

        //consider [l,r],l-1 all < target,r+1 all >= target

        int l=0,r=nums.length-1;

        while(l<=r){

            int mid=l+(r-l>>>1);

            if(nums[mid]<target)l=mid+1;

            else r=mid-1;

        }

        return l;

    }
```
- 注意不变量,l-1始终保持<target,而r+1始终>=target,并选用[l,r]双闭区间写法
## 变式
**假设nums为整数数组**
1. >=x的第一个索引  |  返回 lowerBound(nums,x)
2. >x的第一个索引 | 返回 lowerBound(nums,x+1)
3. <=x的第一个索引 | 返回 lowerBound(nums,x+1)-1
4. <x的第一个索引 | 返回 lowerBound(nums,x)-1

## 核心
- 带有明确**两段一定顺序**的数，都可以使用二分，如寻找峰值和旋转数组
- 另外对于一些**易验证**，**难正面**求解的问题，使用二分快速验证答案也是一种解法，如第k小问题
> 第k小等价于：求最小的x，使满足<=x的数至少有k个
